## 🚀 Key Features

- **Iconic "Who's Watching?" Profile Gate**:
  - Personas: **Brand / Business Owner**, **Agency / Recruiter**, **Creative Director**, or **Casual Explorer**.
- **Cinematic Audio**:
  - Synthesized Netflix "Ta-Dum" bass chime using Web Audio API on project selection and buttons (with 🔊/🔇 mute toggle).
- **Hero Spotlight Billboard**:
  - High-impact featured campaign showcase with match score (`99% Match`), client name, tags, description, and action buttons.
- **Categorized Carousels**:
  - Smooth horizontal navigation (`🔥 Trending Client Work`, `✨ Diva Healthcare Gallery`, `🎙️ The Darshan Shah Show`, `🎨 Iconic Logo Systems & RERA`) with hover expansions.
- **Interactive Netflix Modal ("More Info")**:
  - Campaign breakdown, business ROI metrics, deliverables checklist, client testimonials, and direct WhatsApp / Instagram links.
- **Direct WhatsApp Chat Integration**:
  - Instant one-click connection to **Crown Creation's WhatsApp** with pre-filled project inquiries.
- **"My List" (Watchlist)**:
  - Visitors can bookmark any campaign by clicking `+` (saved in `localStorage`).
- **Live Search**:
  - Instant filtering by client name (`Diva`, `Darshan Shah`, `Gabardine`, `CloneX`), deliverables, or tools.
- **Documentary / Behind the Studio**:
  - Studio numbers (35+ clients, 3.4x ROAS lift, +310% lead surge) and interactive skills matrix.
- **Frequently Asked Questions**:
  - Accordion answering common client questions on timelines, deliverables, and source files.
